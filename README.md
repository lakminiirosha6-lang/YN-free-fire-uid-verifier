# 🔥 Free Fire UID Verifier

A simple and elegant web application to verify Free Fire player UIDs on the SG (Singapore) server.

## Features

✅ **Real-time UID Verification** - Check player information instantly  
✅ **Clean UI** - Modern, responsive design  
✅ **Error Handling** - Helpful error messages  
✅ **Fast Performance** - Optimized for speed  
✅ **Mobile Friendly** - Works on all devices  

## How to Use

1. Enter your Free Fire UID in the input field
2. Click the "VERIFY UID" button
3. View your player profile information instantly

## Information Displayed

- **Nickname** - Your in-game name
- **UID** - Your unique Free Fire ID
- **Server** - SG / Singapore 🇸🇬
- **Level** - Your current level
- **Rank** - Your current rank
- **Ranking Points** - Your ranking points
- **Likes** - Number of likes you have

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Free Fire API

## Installation

No installation required! Just open the web page in any browser.

## API Information

This app uses the Free Fire Info API:
- **Endpoint**: `https://freefireinfo-zy9l.onrender.com/api/v1/player-profile`
- **Server**: SG (Singapore)
- **Method**: GET
